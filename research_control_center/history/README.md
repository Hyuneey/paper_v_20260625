# RCC History

Scientific authority: `2dc7e6c23d5e9503bd4953a70e6bc20e39994b6e`

This directory keeps compact, human-readable records of pivots, consequential
decisions, superseded directions, terminology changes, and RCC checkpoints.
The machine-readable current view remains in `../registry/`; history explains
why that view changed and cannot strengthen an old scientific claim.

Read in this order:

1. `PROJECT_TIMELINE.md`
2. `PROFESSOR_FEEDBACK_LINEAGE.md`
3. `SUPERSEDED_DIRECTIONS.md`
4. `TERMINOLOGY_GUIDE.md`
5. `HISTORY_CONFIRMATION_NEEDED.md`
6. `decisions/`

`decisions/` contains one generated record per consequential registry decision.
`checkpoints/` records material RCC releases. Current claim authority remains
`../registry/claims.csv`.

## GPT conversation policy

GPT conversations are discovery and discussion surfaces, not canonical
historical records.

Persist only consequential decisions, methodological pivots, evidence,
unresolved high-value questions, and resulting next actions. Do not persist
repetitive discussion, exploratory phrasing, emotional commentary, redundant
drafts, or unapproved suggestions.

History records must identify their source and date precision. A fact supported
only by user context remains labeled `USER_CONTEXT` with conservative
confidence; Git must not be presented as independently proving it. Never include
restricted data or private locations.
