# No-rule Taxonomy Audit

Canonical VerifierV1 has no `no_rule` state. The task orchestration can collapse response/parser, validity rejection, non-repairable and budget-exhaustion classes into `no_rule`, contrary to the frozen protocol's separate-counter model. Frozen T2 cases 1–3 were each verified anonymously as call-1 `VALIDITY_UNSUPPORTED_VARIABLE`, non-repairable, no follow-up and no budget exhaustion.
