This directory is the future home for short, human-readable explanations of
research concepts, components, experiments, and claim boundaries. RCC-001
does not create a page for every future topic; RCC-002 will add pages only when
the populated registry needs a durable explanation.

## Editorial rules

- Start from a registry ID and link back to it.
- Separate design intent, implemented behavior, execution evidence, audit
  status, reproduction status, and claim readiness.
- Bind scientific statements to the pinned authority commit.
- Use the thesis overlay for narrative organization only.
- Prefer relationship language over causal language unless a later study
  explicitly supports causality.
- Never copy restricted payloads, private evidence, or private locations into
  the wiki.
