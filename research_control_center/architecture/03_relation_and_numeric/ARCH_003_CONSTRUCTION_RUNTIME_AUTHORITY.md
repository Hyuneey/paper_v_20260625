## Binding and stale-authority prevention

The runtime closes over exact authority-version, COMMON-42, relation-binding, semantic-execution, calibration-policy, normal-input, role, reference, record, and registry hashes. The resolver requires the exact 420 relation-role key set and validates each public rule reference against its private record. The selected horizon is validated from the canonical rule descriptor. Caller-supplied values and stale, missing, duplicate, or foreign keys fail closed.

Units are recoverable from closed role names and formulas—native source/target units, row-seconds, or unitless fractions—but are not first-class fields in the runtime private-record schema. This is a documentation/schema limitation, not evidence of an execution mismatch.

## Can rule text and runtime diverge?

The frozen D1 path does not parse free-form rule text into runtime numbers. It consumes canonical rule descriptors and hash-bound references. A mismatched descriptor/reference/registry cannot validate. Accordingly, silent divergence was not available in the frozen path. This audit does not claim that every future or legacy path has the same protection.
