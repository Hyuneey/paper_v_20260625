# 교수님께 설명할 D1 용어

현재 D1은 “T2가 만든 42개의 Agentic 규칙”을 실행한 평가가 아닙니다. 정상 데이터에서 확인된 42개 관계에 대해 T0, T1, T1-B의 실행 의미가 동일함을 확인하고, 이를 하나의 COMMON-42 V4 rule-descriptor portfolio로 중복 제거한 뒤 normal-only runtime numeric authority에 결속하여 실행했습니다. T2는 39개만 admissible했고 세 건은 `no_rule`이었으며 D1 utility authority에서는 제외되었습니다.

따라서 현재 D1의 권장 명칭은 **COMMON-42 Verified Relational Rule-only**입니다. 여기서 verified는 contract, provenance, hash/integrity 검사를 뜻하며 과학적 진실이나 탐지 성능 검증을 뜻하지 않습니다. “LLM Rule-only”는 T1/T1-B가 construction 비교에 참여했다는 역사적 맥락에서는 부분적으로 이해할 수 있지만 D1 이름으로는 오해를 부릅니다. “Agentic Rule-only”는 T2가 D1에 사용되지 않았으므로 부정확합니다.

진짜 T2/LLM-specific Rule-only 비교를 하려면 T2의 정확한 39개 membership과 세 `no_rule`을 그대로 보존한 별도 portfolio를 사전등록하고, 별도 runtime authority와 독립 평가를 새로 승인해야 합니다.
