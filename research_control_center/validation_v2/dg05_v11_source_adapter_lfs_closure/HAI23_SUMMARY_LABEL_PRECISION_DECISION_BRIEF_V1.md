# User decision brief — HAI23 label/summary timestamp-coordinate conflict

## What is resolved

The HAI23 evaluated panel has 38 official binary positive runs. Together with
the README, technical manual, and summary listing, this establishes that the
summary scalar value 40 does not enumerate 40 physical attack occurrences.

## What remains blocked

The official label payload exposes the evaluated ranges only at a minute-level
timestamp coordinate, while the exact summary interval endpoints are
second-level. The control panel has exact endpoint agreement; the evaluated
panel has zero exact endpoint matches, although all 38 pairs agree after a
minute-floor conversion.

No official source currently authorizes that conversion. Applying it would be
a new scientific time-coordinate rule, so the full triangulation must remain
blocked.
