## Decision options — none selected

### Option 1 — obtain author clarification and machine-readable authority

- Scientific validity: highest; retains official-scenario estimand.
- Thesis defensibility: strongest if response/material is archived and hashed.
- Cross-version comparability: potentially strongest, subject to version-specific answers.
- Implementation cost: low code cost but externally dependent and uncertain latency.
- Post-hoc bias risk: low if questions remain method/result blind.
- Preregistration effect: authority completion; no estimand change if official semantics are supplied.

### Option 2 — prospectively approve a deterministic label/metadata-derived scenario definition

- Scientific validity: defensible only as a new operational definition, not recovered official semantics.
- Thesis defensibility: moderate with explicit limitation and prospective binding.
- Cross-version comparability: potentially weak because available labels/metadata differ by version.
- Implementation cost: moderate; requires version-specific contracts, adversarial tests, and new release qualification.
- Post-hoc bias risk: controllable only if frozen before protected values and predictions are observed.
- Preregistration effect: material amendment to scenario construction and possibly P1 attribution.

### Option 3 — evaluate only versions with complete official authority

- Scientific validity: acceptable only if a version later becomes complete on independent authority.
- Thesis defensibility: reduces replication scope and requires transparent missing-panel rationale.
- Cross-version comparability: reduced or absent.
- Implementation cost: low after authority closure.
- Post-hoc bias risk: moderate unless inclusion is decided solely from authority completeness before results.
- Preregistration effect: removes one or more approved panels and requires explicit amendment.

### Option 4 — prospectively change the primary evaluation unit

- Scientific validity: depends on the new unit and its official support; it answers a different question.
- Thesis defensibility: potentially acceptable but weaker continuity with the frozen scenario-recall design.
- Cross-version comparability: may improve mechanically but could obscure dataset-specific event meaning.
- Implementation cost: high; metric, denominator, delay, statistics, verifier, and release contracts require new versions.
- Post-hoc bias risk: low only if fully frozen before protected access.
- Preregistration effect: major scientific amendment.
