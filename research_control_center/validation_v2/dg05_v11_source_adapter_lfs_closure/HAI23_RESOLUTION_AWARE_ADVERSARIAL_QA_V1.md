# HAI23 resolution-aware authority adversarial QA — V1

The audit rejects or detects mutation of manual occurrence count or identity,
manual target representation, summary record count or endpoint, label range
count or native coordinate, panel-source swap, README census, and every bound
payload hash.

Changing only the scalar summary header is separately detectable as a
provenance mutation. It does not create, remove, or modify an enumerated
canonical scenario object. This distinction is intentional and limited to the
version-bound HAI23 role contract.
