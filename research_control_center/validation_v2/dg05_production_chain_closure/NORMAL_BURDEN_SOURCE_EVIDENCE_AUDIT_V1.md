The frozen normal-burden policy authority identifies version-specific authority classes and aggregation semantics. It does not provide one complete, method-specific source registry that can independently reopen every detector-only, Rule-only, and Fusion alarm vector, timestamp/exposure authority, runtime trace, and method identity needed by the production result route.

Tracked summaries and portfolio guard/audit reports are useful evidence, but they are not interchangeable with the required source bundle. In particular:

- a report decimal is not source evidence;
- a T0 burden cannot stand in for T2;
- Rule-only burden cannot stand in for Fusion burden;
- Fusion burden cannot be derived by adding component burdens;
- configured portfolio membership cannot stand in for observed Rule participation;
- absence of a trace field cannot be interpreted as measured zero.

The prospective `normal_burden_source_registry_v1` and replay implementation require exact method/file components and derive false seconds, file-local row-adjacent episodes, exposure, opportunity coverage, evaluation coverage, and abstention from reopened canonical source bytes. The implementation rejects byte mutation and refuses an incomplete component census.

## Required closure authority

Before a production release can be marked ready, one exact normal-only source authority must enumerate, per panel and method:

- permitted normal file identities and authority class;
- dense normal alarm bytes;
- timestamp/exposure bytes;
- Rule runtime traces where applicable;
- detector, portfolio, and Fusion identities;
- opportunity/evaluation/abstention source bytes;
- source commit and artifact hashes.

If these bytes already exist privately, the next operation is replay and registration only. If they were never persisted, the required authorization is source-materialization only—no held-out/scientific outcome production, fitting, refitting, recalibration, threshold change, method selection, provider call, or new policy.

No private-path absence is inferred from public Git alone. The readiness label is conservative: the current tracked authority set does not demonstrate complete replayable lineage.
