# Continuous-Step Feasibility Preregistration

Train1 and train2 are the candidate-fit periods; train3 is one-way normal
relation calibration. Train3 cannot change source threshold, stability
tolerance, response direction, or horizon. Normal-guard values remain unread.

Fit support requires 20 isolated events total, five per fit file, 0.70 pooled
and 0.60 per-file directional consistency, effect ratio 2.0, and direction
agreement. Calibration requires five isolated train3 events, unchanged source
and target directions, consistency 0.60, and effect ratio 1.0.

Direction and horizon ranking is consistency, effect ratio, shortest horizon,
then lexicographic identity only for an exact computational tie. Multiple
horizons cannot inflate directional pair counts. Unconditioned screening is
permitted only for feasibility; a final rule still requires an approved
operating-regime artifact.
