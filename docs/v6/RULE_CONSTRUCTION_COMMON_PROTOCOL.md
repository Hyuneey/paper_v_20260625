# Common Rule-Construction Protocol

TASK-039E0 preregisters four main construction arms over the same 42 audited
confirmed directional relations and the same logical calibrated construction
evidence.

- T0 produces one deterministic template proposal without an LLM.
- T1 makes one generation call and receives no verifier feedback.
- T1-B makes exactly three independent feedback-free calls, preserves all
  receipts, and selects the lowest admissible call index.
- T2 makes at most three calls and may use bounded deterministic verifier
  feedback and one evidence retrieval action.

All proposals use `canonical_delayed_response_rule_v1_candidate` and
`missing_expected_delayed_response`. Numeric references, rather than invented
runtime literals, bind calibrated evidence. The same deterministic label-free
validity verifier applies to all main arms. A valid proposal is not a runtime
rule and cannot authorize itself.
