# Relation Numeric-Evidence Authority

D1 fit-derived values are classified
`normal_relation_profile_fit_derived`. They are profiling parameters, not rule
or runtime authority. Only a D2-confirmed directional relation may later become
a `ConfirmedRelationPrimitiveV1`, and that primitive is construction evidence,
not a rule.

Future construction evidence may bind the derived source threshold, stability
tolerance, target scale, selected directions and horizon, plus preregistered
windows, stability fraction, refractory interval, and isolation radius. These
values are deterministic; an LLM need not and must not invent them.

Runtime still requires a separately accepted rule, verifier result, governance
decision, immutable rule binding, and deployment authorization. D0 grants none
of those authorities and does not create Rule v2.
