# Candidate Discovery Anti-Leakage Policy

TASK-039BR2 selected P1 after pair-level delayed-response screening. Those
results cannot supervise TASK-039C candidate discovery.

Future C arms may use BR2 pair-level artifacts only to verify lineage hashes.
They may not inspect or use private relation ledgers, directional fit records,
calibration confirmations, supported or confirmed pair identities, target
responses, selected horizons, consistencies, or effect ratios for ranking.

Permitted BR2 source-level reuse is limited to source identity, reviewed
semantic role, and eligibility status. Numeric source thresholds, stability
tolerances, event counts, and event times remain prohibited.

Feature-value permissions are:

| Arm | train1/2 | train3 | train4 | test/labels |
| --- | --- | --- | --- | --- |
| META | No | No | No | No |
| STAT | P1 only | No | No | No |
| GDN | P1 only | No | No | No |

P2, P3, and P4 feature values are prohibited. TASK-039C0 itself accessed no
HAI feature values and executed no discovery method.
