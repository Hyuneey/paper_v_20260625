# Continuous-Step Verifier Migration Plan

A future independent verifier path must perform the 20 ordered checks frozen
in `TASK-039BR1_VERIFIER_MIGRATION_PLAN.json`. They cover schema and
cardinality, reviewed continuous semantics, explicit trigger/directions,
complete parameter provenance, fit-only threshold derivation, lag/response
consistency, evidence/graph/normal-reference binding, normal-only data,
claims, complexity, abstention, authority preclaims, and accepted-rule hash.

Validity excludes normal false-fire, inner utility, detector FN recovery, and
deployment selection. Verifier v1 is unchanged and no new verifier was
implemented in TASK-039BR1.
