# 교수님 이메일 초안

제목: HAI 기반 검증 규칙 구성 연구 첫 결과 및 다음 범위 논의 요청

교수님 안녕하세요.

이전 피드백을 반영해, LLM이 임의 규칙과 수치를 직접 만드는 방향에서 그래프 유도 후보 선별, 정상 데이터 기반 수치 권한, 제한된 규칙 구성, 결정론적 검증과 LLM 없는 실행으로 연구 구조를 바꾸었습니다.

HAI 23.05 P1의 INNER 평가에서 PCA-SPE 기준 탐지기는 14개 공격 이벤트 중 11개를, 규칙 전용은 13개를 탐지했습니다. 규칙은 탐지기가 놓친 3개를 모두 포착해 보완 신호는 확인됐습니다. 그러나 두 결합 정책은 이 3개를 회복하지 못했고 recall 향상 없이 false-alarm 부담만 늘었습니다. 따라서 현재 결론은 “규칙 신호는 존재하지만 현재 결합 utility는 지지되지 않는다”입니다.

OUTER는 허가된 1회 시도가 test2 feature custody 단계에서 바이트를 읽기 전에 중단되어 결과가 없습니다. 이는 부정적 OUTER 결과가 아니라 일반화 미확인 상태입니다.

첨부 보고서에서 구현 구조, 완료/미완료 코드, 하이퍼파라미터 출처, 주장 경계와 대표 설명 사례를 정리했습니다. 특히 다음 네 가지를 상의드리고 싶습니다.

1. 논문 기여를 결합 탐지 성능 향상보다 그래프 유도 규칙 구성·결정론적 검증으로 둘지
2. 실행 규칙과 satisfaction trace를 주 설명 인터페이스로 인정할지, ARTIST식 구간 선택을 추가할지
3. 새 OUTER 연구를 먼저 할지, INNER 범위 주장으로 논문 초안을 먼저 쓸지
4. PCA-SPE 외 강한 detector baseline 하나를 추가할지

저의 권고는 교수님 피드백을 받은 뒤 논문 초안을 우선 진행하는 것입니다. 10–15분 정도 결과를 보고드리고 다음 범위를 결정할 수 있으면 좋겠습니다.

감사합니다.
