# 교수님께 먼저 드리는 안내

## 연구 주제

정상 운전 데이터에서 다변량 공정 변수의 시간적 관계를 발견하고,
이를 **사람이 읽고 실행할 수 있는 검증된 시간 규칙**으로 구성하는
설명 가능한 이상탐지 연구입니다.

## 현재 단계

HAI 23.05 P1 Boiler를 대상으로 후보 관계 발견, 정상 데이터 기반 관계
프로파일링, 제한된 LLM 보조 규칙 구성, 결정론적 검증, 규칙 실행,
기준 탐지기와의 INNER 비교까지 완료했습니다. 42개 검증 관계 규칙을
평가했으며, held-out OUTER 평가는 과학 결과를 만들지 못했습니다.

## 핵심 결과

- 기준 탐지기 D0: 공격 이벤트 14개 중 11개 탐지
- 규칙 계층 D1: 14개 중 13개 탐지, D0가 놓친 3개를 모두 탐지
- 그러나 규칙 단독의 정상 오경보가 매우 많음
- 두 결합 정책 D2 V1/V2: D0 미탐 회복 `0/3`, recall 개선 없음

**해석:** 규칙 신호의 이벤트 수준 보완성은 확인됐지만, 현재 결합
정책이 이를 탐지 성능 향상으로 전환했다는 근거는 없습니다.

## 핵심 한계

TSFM과 ARTIST식 세그먼트 선택은 구현하지 않았고, 사람 대상 설명
유용성 평가와 강한 탐지기 기준선 비교도 아직 없습니다. OUTER는
test2 데이터를 읽기 전에 중단되어 일반화가 확인되지 않았습니다.

2. 시간 규칙과 만족 trace를 설명 인터페이스로 인정할지
3. INNER 범위 논문 초안을 먼저 쓸지, 새 OUTER 연구를 먼저 할지
4. PCA-SPE 외 강한 기준 탐지기 하나를 추가할지
