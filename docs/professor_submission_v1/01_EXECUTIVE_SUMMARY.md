# 1차 연구 결과 실행 요약

## 1. 해결하려는 문제

다변량 이상탐지기는 이상 여부를 알려줄 수 있지만, 어떤 변수의 어떤
변화가 얼마 뒤 다른 변수의 기대 반응과 어긋났는지를 사람이 읽을 수
있는 형태로 설명하는 데 한계가 있습니다. 본 연구는 정상 공정에서
학습한 시간적 변수 관계를 검증 가능한 규칙으로 만들고, 이 규칙이
기준 탐지기의 미탐에 보완 정보를 제공하는지 묻습니다.

## 2. 제안 방법

```text
그래프 유도 관계 후보 발견
→ 정상 데이터 기반 시간 관계 프로파일링
→ 제한된 LLM 보조 규칙 구성
→ 정상 데이터에서만 숫자 결정
→ 결정론적 검증
→ LLM 없는 규칙 실행과 만족 trace
```

LLM은 허용된 관계 구조 안에서만 규칙 형식을 제안합니다. 수치
파라미터, 최종 유효성, 실행 결과는 LLM이 결정하지 않습니다.

## 3. 현재까지 구현한 범위

- HAI 23.05 P1 Boiler의 그래프 유도 후보 관계 발견
- 정상 데이터 기반 delayed-response 프로파일링
- 42개 확인 관계로 구성된 verified temporal rule portfolio
- 제한된 규칙 구성 방식 T0/T1/T1-B/T2 비교
- 결정론적 수치 참조와 verifier
- LLM-free 규칙 런타임과 rule-satisfaction trace
- PCA-SPE 기준 탐지기 D0, 규칙 탐지 D1, 두 결합 정책 D2 V1/V2
- 이벤트 recall과 정상 FAR/hour 평가

TSFM과 ARTIST식 세그먼트 선택은 현재 구현하지 않았습니다.

## 4. 첫 INNER 결과

| 방법 | Attack-event Recall | Normal FAR/hour | D0 미탐 회복 |
|---|---:|---:|---:|
| D0 기준 탐지기 | 0.7857142857142857 | 0.4939336325682589 | 기준 |
| D1 verified rules | 0.9285714285714286 | 40.50255787059723 | 3/3 |
| D2 V1 combined fusion | 0.7857142857142857 | 0.7056194750975128 | 0/3 |
| D2 V2 combined fusion | 0.7857142857142857 | 6.915070855955625 | 0/3 |

D0와 D1의 이벤트 합집합은 `14/14`였습니다. 즉 규칙 계층에는 기준
탐지기가 놓친 이벤트에 대한 보완 신호가 있었습니다. 다만 D1의
오경보 부담이 매우 컸고, 두 결합 정책 모두 이 신호를 D0 대비 recall
향상으로 바꾸지 못했습니다. 공격 이벤트가 14개뿐이므로 통계적
우월성을 주장하지 않습니다.

## 5. 과학적 결론

`RULE_SIGNAL_PRESENT_BUT_CURRENT_FUSION_UTILITY_UNSUPPORTED`

- **작동한 것:** 그래프 유도 관계 발견, 검증 규칙 구성, LLM 없는
  실행, 이벤트 수준 detector–rule complementarity
- **작동하지 않은 것:** 규칙 단독의 운용 가능한 오경보 수준, V1/V2
  결합을 통한 D0 미탐 회복
- **아직 모르는 것:** held-out 일반화, TSFM/ARTIST의 효과, 사람에게
  설명이 실제로 유용한지, 더 강한 탐지기에서도 보완성이 유지되는지

## 6. 잠정 기여 문장

**PROVISIONAL_PENDING_PROFESSOR_APPROVAL**

1. 정상 CPS 데이터에서 다변량 시간 관계를 그래프 유도로 발견·확인
2. LLM의 역할을 제한하고 숫자와 최종 유효성을 결정론적으로 통제하는
   규칙 구성 workflow
3. 시간 변수 관계를 설명하는 실행 가능한 규칙과 만족 trace
4. detector–rule 보완성 및 현재 결합 정책의 실패를 함께 공개한 실증
   분석

## 7. OUTER 범위

사전등록된 held-out 평가는 과학 결과를 만들지 못했습니다. test2
feature bytes나 label을 읽기 전에 데이터 관리 경계에서 실행이
중단됐습니다. 따라서 held-out 결과 정보는 관측되지 않았으며, 현재
주장은 INNER 평가로 제한됩니다.

정리했습니다.
