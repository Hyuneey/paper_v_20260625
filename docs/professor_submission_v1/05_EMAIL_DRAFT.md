# 교수님 이메일 초안

**제목: HAI 기반 검증 시간 규칙 연구 1차 결과 및 연구 범위 논의 요청**

교수님 안녕하세요.

이전에 주신 피드백을 반영해, LLM이 규칙과 수치를 자유롭게 생성하는
방향에서 그래프 유도 관계 발견, 정상 데이터 기반 수치 결정, 제한된
규칙 구성, 결정론적 검증과 LLM 없는 실행으로 연구 구조를
조정했습니다.

현재 HAI 23.05 P1 대상 1차 구현과 INNER 평가를 완료했습니다. 기준
탐지기는 14개 공격 이벤트 중 11개를, 검증 규칙 계층은 13개를
탐지했습니다. 규칙은 기준 탐지기가 놓친 3개 이벤트를 모두 찾아
보완 신호를 보였지만, 오경보가 많았고 두 결합 정책은 이 신호를
recall 향상으로 전환하지 못했습니다.

따라서 현재 기여를 결합 성능 향상보다 그래프 유도 규칙 구성,
결정론적 검증, 실행 가능한 시간 관계 설명에 두는 것이 적절하다고
판단하고 있습니다. held-out 평가는 데이터 읽기 전에 중단되어 결과가
없으며, 현재 주장은 INNER 범위로 제한했습니다.

첨부한 짧은 보고서와 결과표를 검토해 주시면 감사하겠습니다. 특히
다음 네 가지를 상의드리고 싶습니다.

1. 논문 기여를 규칙 구성·결정론적 검증으로 확정할지
2. 시간 규칙과 만족 trace를 주 설명 인터페이스로 인정할지
3. 논문 초안을 먼저 시작할지, 새 독립 OUTER 연구를 먼저 할지
4. PCA-SPE 외 강한 기준 탐지기 하나가 필요한지

저의 권고는 교수님 피드백을 반영해 논문 초안을 우선 시작하고,
추가 실험은 필요성이 확인된 항목만 별도로 설계하는 것입니다.
가능하신 시간에 10–15분 정도 결과를 보고드리고 다음 범위를
결정하고 싶습니다.

감사합니다.
