# 교수님께 요청드리는 네 결정

## Decision 1 — 논문 기여의 중심

**질문:** 논문 기여를 “결합 탐지기 성능 향상”이 아니라 **그래프 유도
규칙 구성과 결정론적 검증**으로 두어도 될까요?

**권고: YES.** 현재 구현과 결과가 가장 직접적으로 지지하는
기여입니다. 승인되면 연구 질문·초록·기여 목록을 이 축으로 정렬하고,
결합 결과는 정직한 negative evidence로 보고하겠습니다.

## Decision 2 — 설명 인터페이스

**질문:** 실행 가능한 시간 규칙과 rule-satisfaction trace를 주 설명
인터페이스로 인정할까요, 아니면 ARTIST식 세그먼트 선택 모듈을
추가해야 할까요?

**권고:** 세그먼트 선택이 논문의 필수 요건이라고 보시지 않는 한 현재
규칙-trace 인터페이스를 유지하고 ARTIST는 향후 연구로 두겠습니다.
추가 시 논문 범위와 평가 설계가 크게 늘어납니다.

## Decision 3 — 검증 순서

**질문:** INNER 범위 주장으로 논문 초안을 먼저 시작할까요, 아니면
새로 사전등록한 독립 OUTER 연구를 먼저 수행할까요?

**권고: THESIS_FIRST.** 현재 결과와 한계를 먼저 논문화하고, held-out
일반화가 필수라는 판단이 있을 때만 별도 OUTER 연구를 설계하겠습니다.
기존 시도를 자동 재개하지는 않겠습니다.

## Decision 4 — 기준 탐지기

**질문:** PCA-SPE가 첫 reference detector로 충분할까요, 아니면 더
강한 다변량 탐지기 하나를 추가해야 할까요?

**권고:** 첫 보고와 초안에는 PCA-SPE를 명확한 reference baseline으로
유지하고, 교수님이 심사 위험이 크다고 판단하실 때만 하나의 강한
baseline을 새 실험으로 추가하겠습니다.

## 권고 기본 경로

**`THESIS_FIRST_PENDING_PROFESSOR_FEEDBACK`**

위 네 결정 전에는 D2 V3, OUTER 재시도, TSFM/ARTIST 추가, 데이터셋
확장, 새 detector 실험을 시작하지 않습니다.
