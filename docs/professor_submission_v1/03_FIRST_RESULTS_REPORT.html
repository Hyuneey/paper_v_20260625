규칙 계층은 기준 탐지기의 미탐에 보완 신호를 보였지만, 현재 두 결합 정책은 이를 incremental detector utility로 전환하지 못했습니다.

1. 연구 문제와 접근

다변량 탐지기의 경보를 사람에게 읽히는 시간 변수 관계로 설명하기 위해, 정상 운전 데이터에서 delayed-response 관계를 발견하고 실행 가능한 verified temporal rule로 변환합니다. LLM은 제한된 구조만 제안하며 숫자, 최종 validity, runtime은 결정론적으로 통제됩니다.

2. 구현된 범위

  • HAI 23.05 P1 Boiler의 144개 후보쌍과 정상 데이터 관계 profiling
  • 23개 변수쌍, 42개 방향 관계의 verified temporal rule portfolio
  • bounded rule construction, normal-only numeric control, deterministic verifier
  • D0 PCA-SPE, D1 rule detector, D2 V1/V2 combined fusion
  • event recall, normal FAR/hour, rule-satisfaction trace

5. OUTER와 주장 범위

사전등록된 held-out 평가는 과학 결과를 만들지 못했습니다. 실행은 test2 feature bytes나 labels를 읽기 전 데이터 관리 경계에서 중단됐습니다. 따라서 held-out outcome은 관측되지 않았고 현재 실증 주장은 INNER 평가로 제한됩니다. 이는 부정적 OUTER 과학 결과가 아닙니다.

지원되는 기여는 그래프 유도 관계 발견, 정상 데이터 수치 통제, 실행 가능한 검증 규칙, deterministic verification, LLM-free runtime, INNER event-level complementarity와 transparent negative fusion evidence입니다. combined improvement, causal root cause, held-out generalization은 주장하지 않습니다.

6. 교수님께 요청드리는 네 결정

1. 기여 framing — graph-guided rule construction와 deterministic verification로 둘까요? 권고: YES.
2. 설명 interface — temporal rules와 satisfaction traces로 충분한가요, ARTIST식 segment selection이 필수인가요? 권고: 현재 interface 유지.
3. 검증 순서 — INNER 범위 논문 초안을 먼저 쓸까요, 새 OUTER 연구를 먼저 할까요? 권고: THESIS_FIRST.
4. detector baseline — PCA-SPE로 충분한가요, 강한 baseline 하나가 더 필요한가요? 권고: 요청 시 1개 추가.

본 문서는 이미 동결된 INNER 결과의 교수 보고용 요약입니다. 새로운 과학 실행, 파라미터 변경 또는 held-out 데이터 접근을 포함하지 않습니다.
