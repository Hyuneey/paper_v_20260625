# Research scope

## Framing

**Graph-Guided Agentic Rule Construction with Deterministic Verification for
Explainable Multivariate Time-Series Anomaly Detection**

## Core pipeline

HAI normal data and process metadata → process/statistical/GNN candidate
relations → normal relation confirmation → normal-data numeric authority →
bounded LLM rule construction → deterministic verification → COMMON-42 →
LLM-free runtime → D1 Rule-only → future D0/D2 comparison.

## Current dataset, process, and portfolio

- Primary dataset: HAI 23.05.
- Process: P1 Boiler.
- Portfolio: COMMON-42, exactly 42 relations.
- T2 utility membership: not authorized.

## Experiment order

1. D1 Rule-only INNER test1.
2. D1 result-integrity audit.
3. Detector authority and baseline.
4. D0/D1/D2 INNER comparison using the same frozen D1 predictions.
5. Policy freeze.
6. Sealed OUTER test2.

## Explicit non-claims

- Verified rule construction is not proof of utility.
- Utility has not executed.
- Detector improvement has not been demonstrated.
- Causality and root cause are not claimed.
- Runtime LLM is prohibited.
